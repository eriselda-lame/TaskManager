# Task Manager

A desktop task management application built with Java Swing.

## Features
- User profile creation and login
- Password verification
- Add and delete tasks
- Task categories: Study Task, Home Task, Others
- Priority levels and due dates
- Completed and pending task views
- Daily progress tracker
- Light and night modes
- Local data storage

## Technologies
- Java
- Java Swing
- Apache NetBeans
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project in Apache NetBeans.
3. Set `taskmanager.TaskManagerApp` as the main class.
4. Run the project.
